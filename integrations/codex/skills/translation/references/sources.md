# Sources

The rules in this skill were extracted from the works below, reading each in full, and
kept only where they were specific enough to act on and not something a capable model
does unprompted. For every reference file a record was kept of which extracted rules it
uses, and this list is generated from that record. After each work: the reference files
that draw on it.

Where sources disagreed, the reference files state the condition under which each rule
applies instead of choosing one. A few rules restate advice for human translators in a
form a model can act on (for instance, a pause before re-reading becomes a pass in a
fresh context); those adaptations are the skill author's, not the sources'.

The language notes were drafted section by section from the extracted rules and then
cut hard, so the works listed for a language file may include some whose points did
not survive. Their examples were copied from the sources; examples in right-to-left
scripts were corrected where extraction from PDF had reversed them.
